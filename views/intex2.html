INTEX 2

C# ASP.NET Machine Learning Azure

Description

INTEX is a team case competition held each semester of the BYU Information Systems junior core. For this round, in April 2024, my team of four was challenged to build a storefront web application in four days, with features supported by strong cybersecurity standards and machine learning pipelines.

The application was written in C# with ASP.NET, with an HTML/CSS storefront frontend, and was originally deployed with Microsoft Azure. The compressed timeline meant designing the data model, security posture, ML integration, and user experience in parallel — a sprint from blank repository to deployed product in under a week.

Built with a team of four BYU Information Systems students.
